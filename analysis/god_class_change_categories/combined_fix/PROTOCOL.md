# Combined fix-labelled category and thesis figure

This is a post-hoc presentation and refit requested after the v1.1 category study. It uses precisely the v1.1 comparison file rows, their mutually exclusive categories, covariates and 365-day windows. The only outcome transformation is `fix_labelled = issue_linked_fix_labelled + other_fix_labelled`. All other categories remain unchanged. Fit a new Poisson pseudo-maximum-likelihood model for the combined count; do not add or average the separate count ratios. Refit all displayed categories with the original spline/year design and two-way lineage/year clustered uncertainty. Apply Holm correction across fitted category comparisons; display 95% intervals without multiplicity adjustment and give adjusted p-values in the accompanying table.

The publication figure has one panel for Jenkins and one for Tomcat. It shows all eight mutually exclusive high-level title-cue categories plus the total change-count ratio as a reference row. A vertical line at one denotes equal adjusted mean counts. Sparse categories have no ratio and are explicitly marked as not estimated. Use a common logarithmic ratio axis, a vector PDF, a raster preview and a self-contained caption. Preserve category event counts and provenance. These categories describe commit wording, not verified defects, feature work, security work or developer time. The figure is exploratory and not a causal estimate.
