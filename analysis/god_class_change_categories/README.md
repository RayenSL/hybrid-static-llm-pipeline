Run from the repository root:

```bash
python3 analysis/god_class_change_categories/run_v1_1.py \
  --packages /tmp/bugfix-statistics \
  --output /tmp/god-class-categories-replay
```

The script reads the sealed corrected cohort, archived model table, local first-parent Git histories and file-event SQLite databases. Restore the pinned statistics runtime and histories using `analysis/maintenance_associations/README.md` if necessary. A fresh run must reproduce the `SHA256SUMS.json` in `results/v1.1` exactly. The original total-change count and two repository-specific ratios are checked in the script before any category results are released.

For thesis use, the [combined fix-labelled figure and LaTeX insertion](combined_fix/README.md) replace the separate issue-linked and other-fix category presentation. The detailed v1.1 labels remain available for audit.
