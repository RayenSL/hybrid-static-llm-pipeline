Extract pricing/onderbouwing logic into a helper method. 5. Consider a strategy pattern or visitor if more item types are expected. Example: ```csharp public BBegroting MaakBegroting(string naam, IList<IKostenbestandRaadplegenItem> regels, bool inclusiefOnderbouwing, BBrinkKostenbestandEigenschappen kbEgs) { var context = new BegrotingContext(kbEgs); var bgr = new BBegroting(naam, BBegroting.GeefStdBasisValuta(), new BegrotingMaxIdBepaler()); bgr.WijzigBgrTpe(EBgrTpe.Elementen); foreach (var item in regels) { switch (item) { case BKlasseWrapper c: VerwerkClassificatie(bgr, context, c); break; case BElementWrapper e: VerwerkElement(bgr, context, e, inclusiefOnderbouwing); break; case BActiviteitWrapper a: VerwerkActiviteit(bgr, context, a, inclusiefOnderbouwing); break; case BMiddelWrapper m: VerwerkMiddel(bgr, context, m); break; } } return bgr; } ``` This reduces method size, isolates business rules, and makes each branch independently testable.
