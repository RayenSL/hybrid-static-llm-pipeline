# Previous-run archive — 2026-07-27

This directory contains execution artifacts that predate the generated-test
factorial pilot and campaign.

Archived groups:

- `runs/`: root run records, iterative trajectories, verification records,
  quality records, private Layer 3 records, and the phase-C run log;
- `src/runs/`: earlier exploratory run records;
- `output/`: figures and tables generated from the previous runs;
- `analysis/output/`: the previous analysis output directory.

The already-separated, versioned `src/runs-archive-pre-v1.1.0/` archive remains
in its original location. The non-evaluation fixture under `pilot/` is also not
part of this archive.

No artifacts were deleted. `INVENTORY.txt` records file paths and sizes, while
`SHA256SUMS` records content hashes for integrity verification.
